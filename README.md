# VoltCheck Pro

볼트체크 24V는 전기·전장, 모터, 기계, 유체, HVAC, 배터리, 로봇 분야 실무자를 위한 정적 웹 기반 산업 공학 계산 포털입니다. GitHub Pages에서 배포되며, 브라우저 안에서 계산 입력, 결과 판정, 공유 링크, A4 기술검토서 출력을 제공합니다.

## 주요 기능

- 24V 전압강하 및 센서 전원 마진 검증
- 4-20mA 루프, SMPS/제어전원, 제어반 쿨링 계산
- AWG/SQ 전선 조견표, RS-485 통신선로, 공압 소모량 계산
- 3상 모터·전자접촉기, 베어링 수명, CNC 절삭력, 배관 마찰손실, 압력용기 두께 등 78대 산업 공학 계산 도구
- 계산 조건 공유, 즐겨찾기, 로컬 프로젝트 저장, 통합 A4 기술검토서 출력
- 개인정보처리방침, 이용약관, 문의, 업데이트 페이지 포함

## 프로젝트 구조

- `index.html`: 계산기 UI, SEO 메타, 정적 페이지 마크업
- `styles.css`: 산업 계측기 콘셉트의 반응형 디자인 시스템
- `app.js`: 계산 로직, 탭 전환, 검색, 로컬 저장, 출력 기능
- `manifest.json`: PWA 메타데이터
- `robots.txt`, `sitemap.xml`, `rss.xml`: 검색엔진/콘텐츠 피드용 파일
- `assets/downloads/`: 다운로드형 템플릿과 참고 파일
- `docs/`: 제품 개선, 검증, 운영 문서

## 운영 원칙

계산 결과는 설계 검토와 현장 판단을 돕기 위한 참고값입니다. 최종 설계, 안전 인증, 법규 적용, 구매 사양 확정에는 현장 조건, 제조사 데이터시트, 최신 법규와 표준을 우선 적용해야 합니다.

## 권장 개선 로드맵

1. 계산기별 순수 계산 함수와 DOM 렌더링 로직 분리
2. 대표 계산기부터 입력 검증과 기준값 회귀 테스트 추가
3. 계산기별 독립 URL 및 카테고리 페이지 도입
4. 대형 미디어 자산을 별도 CDN 또는 릴리즈 자산으로 분리
5. 검증 가능한 공식 출처, 적용 한계, 예제 계산을 각 도구별로 보강
