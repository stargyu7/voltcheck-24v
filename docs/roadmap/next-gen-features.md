## 기능 1. 실측값 비교 로그 (현장 검증 데이터베이스 & 커뮤니티 벤치마크)
- **목적**: 계산기 예측값과 사용자의 실제 현장 측정값을 나란히 비교하고, 데이터를 익명 누적해 "동일 조건 실측 평균"을 사이트 자체 콘텐츠로 노출.
- **오차율 산출식**: `|실측값 - 계산예측값| / 계산예측값 × 100 (%)`
- **핵심 UI**: 계산 결과 패널 하단 "현장에서 실제로 측정하셨나요?" 실측치 입력 + 오차 분석 뱃지 + 누적 통계 배지.

---

## 기능 2. 프로젝트 저장 & 팀 공유 링크 (Project Workspace & Snapshot Token)
- **목적**: 여러 계산기 결과(전압강하 + SMPS + 쿨링 + 접지 + 모터 등)를 "프로젝트" 단위로 묶어 팀원에게 URL 하나로 공유.
- **UI 흐름**: 우측 하단 플로팅 "프로젝트 보관함" 위젯 + "프로젝트에 추가" 버튼 + URL 해시 기반 스냅샷 토큰 공유 + 프로젝트 일괄 A4 종합 기술검토서 출력.

---

## 기능 3. 실구매 가능 부품번호 매칭 (BOM 자동 생성 & 카탈로그 매핑)
- **목적**: 계산 결과("AWG 24 이상", "24V 10A SMPS", "2A C-curve CP")를 실제 제조사(대한전선, LS ELECTRIC, Schneider, MEAN WELL, LAPP Korea 등) 공식 카탈로그 품번 및 단가대와 자동 매칭.
- **UI 흐름**: "실제 구매 가능 제품 보기 (BOM)" 토글 및 파트 카드 노출, 견적함 일괄 담기 연동.

---

## 기능 4. 구리시세(LME) 연동 케이블 원가 계산기 (Copper Spot Price & Cable Sizing)
- **목적**: 국제 구리 시세(LME Copper)를 반영하여 케이블 100m/드럼 발주 시 원가를 실시간 산출.
- **산출 로직**:
  - 구리 중량(kg/km) = 도체 단면적(mm²) × 8.96 × 1000 / 1000 = 단면적 × 8.96
  - 케이블 원가(원/m) = (구리 중량 × 구리단가/kg ÷ 1000) + 절연/피복 원가 × 가공계수(1.4~1.8)
- **UI 흐름**: 전용 계산기 탭 + AWG 조견표 내 실시간 원가 컬럼 + 30일 구리가격 추이 미니 차트.

---

## 기능 5. 결선도/단선도(SLD) 자동 생성기 (SVG → Canvas → PNG / PDF / DXF Export)
- **목적**: 전압강하 및 전장 설계 입력값을 기반으로 24V SMPS → 차단기(CP) → 케이블 선로 → 단자대 → 부하/센서 표준 단선결선도(SLD) 자동 생성.
- **출력 포맷**:
  - 인터랙티브 SVG 렌더링
  - 고해상도 PNG / A4 PDF 출력
  - AutoCAD / EPLAN / SolidWorks 호환 **DXF (Drawing Exchange Format) CAD 파일 다운로드**
